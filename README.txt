A YEAR OF US — anniversary website
====================================

1. Unzip this folder.
2. Open the `photos` folder.
3. Copy your 18 original photos into it, keeping the filenames exactly as listed below.
4. Double-click `index.html` to preview the website in your browser.
5. To publish on GitHub Pages, upload the contents of this folder to a GitHub repository, then enable Pages in Settings → Pages → Deploy from a branch → main → /(root).

The site is static: no server, build step, database, or paid hosting required.
It uses Google Fonts when online; system fallback fonts are used if offline.

Personalisation:
- Edit the wording directly in `index.html`.
- Change the anniversary dates in the hero and footer if needed.
- Photos are intentionally not bundled because they are on your computer; put them in `photos/`.
